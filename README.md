# 🚌 RodosBus

O **RodosBus** é um projeto acadêmico desenvolvido no curso de **Análise e Desenvolvimento de Sistemas** do **Centro Universitário Senac**.  
A plataforma tem como objetivo facilitar a **reserva de passagens de ônibus**, oferecendo uma experiência simples, organizada e eficiente para os usuários.

---

## 🎯 Objetivo do Projeto

Criar um sistema que permita:
- Consulta de viagens disponíveis
- Reserva de passagens de ônibus
- Organização e gerenciamento das informações
- Aplicação de boas práticas de desenvolvimento de software

O projeto foi desenvolvido como parte das atividades acadêmicas, com foco em aprendizado prático, trabalho em equipe e estruturação de sistemas reais.

---

## 🛠️ Funcionalidades Principais

- Cadastro e login de usuários  
- Consulta de viagens  
- Reserva de passagens  
- Gerenciamento de dados  
- Interface simples e intuitiva  

---

## 🧑‍💻 Tecnologias Utilizadas

- CSS
